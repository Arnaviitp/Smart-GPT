# Smart-GPT 🤖

A lightweight, responsive, and intelligent chatbot interface powered by OpenAI's GPT models. Deployed using Vercel and built with modern web technologies, Smart-GPT aims to deliver a seamless user experience for interacting with powerful AI models.

> 🚀 [Live Demo](https://smart-gpt-nine.vercel.app)

---

## 📌 Features

- ⚡ Fast and responsive chat interface
- 🧠 Powered by GPT (via OpenAI API)
- 🌙 Light & dark theme support (optional)
- 📱 Mobile-friendly and accessible design
- 🎯 Easy to deploy on Vercel or your preferred platform

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **Next.js** | Frontend framework |

| **OpenAI API** | GPT model integration |

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Arnaviitp/Smart-GPT.git
cd Smart-GPT
````

### 2. Install Dependencies

```bash
npm install
```

### 3. Set Up Environment Variables

Create a `.env.local` file in the root directory with the following:

```bash
OPENAI_API_KEY=your_openai_api_key_here
```

> Get your API key from [OpenAI](https://platform.openai.com/account/api-keys)

### 4. Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌍 Deployment

This project is optimized for [Vercel](https://vercel.com/). To deploy:

1. Push your code to GitHub.
2. Import the repo into your Vercel dashboard.
3. Set the required environment variables.
4. Deploy and share!
